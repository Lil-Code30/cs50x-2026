# Week 1 C

[Week 1 C](https://cs50.harvard.edu/x/2026/weeks/1/)

## Overview

In Week 1 of CS50, we delve into the C programming language, which is a foundational language in computer science. This week covers essential concepts such as data types, variables, control structures, functions, and arrays. Students will learn how to write, compile, and debug C programs, gaining a deeper understanding of how computers operate at a low level.

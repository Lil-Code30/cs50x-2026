# Game : Catch the Falling Yellow Stars

In this game, the player controls a character that moves left and right to catch falling yellow stars while avoiding other objects. The objective is to catch as many yellow stars as possible to score points.

Instructions :
— Move Dot (the yellow Dog) with the Left and Right Arrows of your keyboard to catch the stars.
— Catch the Yellow star
— Do not catch the red star or else your life will reduce by 1
— When you have 2 lives remaining, a heart will fall until you catch it.
— The Game ends when there are no lives remaining

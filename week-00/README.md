# Week 0 Sratch

[Week 0 Sratch](https://cs50.harvard.edu/x/2026/weeks/0/)

This week we learned the basics of programming using Scratch, a visual programming language. We created simple programs by snapping together blocks that represent different commands and control structures.

We covered concepts such as sequences, loops, conditionals, and events. By the end of the week, we built a small interactive game that demonstrated our understanding of these fundamental programming concepts.
